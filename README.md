# SoftGrid Weather App - Rameen

Simple weather application built for SoftGrid assignment using HTML, CSS, and JavaScript.

## Features
- Search weather by city name
- Shows temperature, humidity, wind speed
- Displays weather icon and description
- Error handling for invalid cities
- Clean, responsive UI

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- OpenWeatherMap API

## How to Run
1. Clone or download this repo
2. Open `index.html` in your browser
3. Enter city name and click Search

## API Key
This project uses OpenWeatherMap API. Get your free API key from https://openweathermap.org/api
